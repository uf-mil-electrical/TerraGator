## Overview

The time-of-flight (ToF) breakout board is a small PCB that can be used for collision detection on TerraGator. The plan is to mount one all four sides of TerraGator so that we can minimize collisions between objects and the rover. 

## Documentation

For more information on the ToF sensor used (VL53L1X) and ToF breakout board can be found on the MIL wiki.
